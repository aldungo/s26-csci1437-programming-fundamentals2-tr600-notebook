### 2️⃣ Run Code in the Cloud (Recommended!)
Want to actually **run and experiment** with the code? Use GitHub Codespaces - it's a free cloud computer with Java already installed!

**Steps:**
1. Click this link: [Open Course Codespace](https://codespaces.new/aldungo/s26-csci1437-programming-fundamentals2-tr600-notebook?quickstart=1)
2. Sign in with your GitHub account (create one if needed - it's free!)
3. Click "Create codespace"
4. Wait 30 seconds for your workspace to load
5. You now have a full Java development environment in your browser! 🎉

**Important Tips:**
- ✅ Create **ONE** Codespace at the start of the semester
- ✅ **Reuse** that same Codespace all semester (don't make new ones each time!)
- ✅ Your work is **private** - only you can see it
- ✅ You get **60 free hours per month** (plenty for class!)
- ✅ **Stop your Codespace** when done (saves your free hours)

## ❓ Common Questions

**Q: Do I need to install Java on my computer?**  
A: No! If you use Codespaces, everything runs in the cloud. But you're welcome to install locally if you prefer.

**Q: Will other students see my code if I use Codespaces?**  
A: No! Your Codespace is completely private. Only you can see your work.

**Q: What if I mess up the code?**  
A: No worries! You can always get fresh code from the repository. Your changes don't affect the original.

**Q: How do I get the latest examples after each class?**  
A: In your Codespace terminal, type: `git pull origin main`

**Q: I ran out of free Codespace hours. What now?**  
A: You can clone the repository to your computer and work locally, or wait for your hours to reset next month.

**Q: Can I use this for my assignments?**  
A: You can **reference** the examples, but assignments must be your own work. Don't copy-paste solutions!
