▪JavaFX uses a theater analogy to describe GUI applications
▪Stage class represents the application window
▪Scene class represents the collection of nodes (actors) for the application
▪Nodes represent various visual elements for the application

Panes, UI Controls, and Shapes
Panes, UI Controls, and Shapes
public void start(Stage primaryStage) {
Circle circle= new Circle();
circle.setCenterX(100);
circle.setCenterY(100);
circle.setRadius(50);
circle.setStroke(Color.BLACK);
circle.setFill(Color.WHITE);
// remainder of start method
Pane pane= new Pane();
pane.getChildren().add(circle);
Scene scene= new Scene(pane, 200, 200);
primaryStage.setScene(scene);
primaryStage.setTitle(“Show Circle”);
primaryStage.show();
}
▪Previous program shows how you can set up most JavaFX applications
▪Implement individual nodes first
▪Then implement containers to put nodes into
▪Then implement scene object
▪Then prepare stage

▪Adding images to JavaFX requires two classes: Image and ImageView
▪Image class used to load image files into a program
• Relative file path from project directory using file protocol
• http protocol to load images from a webpage
▪ImageViewclass used to create nodes for displaying images
• Dimensions of images specified through ImageViewobjects
• To keep dimensions consistent, be sure to preserve the aspect ratio

▪Property binding binds target object to source object
▪Target is binding object or binding property
▪Source is bindable object or observable object
circle.centerXProperty().bind(pane.widthProperty().divide(2));
circle.centerYProperty().bind(pane.heightProperty().divide(2));
Property Binding
▪bind method is defined in Property interface
• Binding property is an instance of Property interface
▪Observable source object is instance of ObservableValueinterface
▪Common binding properties include DoubleProperty, IntegerProperty, etc.
Property Binding
▪Binding properties include getter and setter methods
• Getter and setter methods for binding property’s value (value getter and value 
setter)
• Getter method for binding property itself (property getter)
▪centerXProperty() returns an object of the DoublePropertytype
▪getCenterX() returns a double value
▪Numeric binding property classes contain add, subtract, divide, and 
multiply
• Return a new observable property
Property Binding
▪Example of Circle and window is unidirectional binding
• Changes are only observed in one direction
▪May also require bidirectional binding
• Changes in either object are observed by the other
• Use bindBidirectionalmethod
