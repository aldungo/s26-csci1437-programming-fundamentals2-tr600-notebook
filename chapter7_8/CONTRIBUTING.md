# Contributing to Programming Fundamentals 1 Class Repository

Thank you for your interest in contributing! This repository is for public-facing examples, demos, and lecture materials. Please follow these guidelines:

## What to Contribute
- Lecture code examples
- Demo programs
- Practice exercises
- Helpful resources for students

## What NOT to Contribute
- Graded solutions or answer keys
- Student submissions for assignments
- Sensitive or private information

## How to Contribute
1. Fork the repository and create a new branch for your changes.
2. Add your files to the appropriate folder (`lectures/`, `examples/`, or `demos/`).
3. Submit a pull request with a clear description of your changes.

## Code Style
- Use clear, descriptive names for files and classes.
- Include comments explaining the purpose of your code.
- Follow Java best practices and formatting.

## Questions?
Open an issue or contact the instructor for guidance.

---
This repository is always public and up-to-date for student reference. Please help us keep it clean and useful for everyone!
